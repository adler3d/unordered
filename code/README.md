# 🧪 Mashkod & Qap: Лаборатория мета-игрового кода

> *"Не пиши игру. Пиши язык, на котором игра напишет себя."*

Этот репозиторий — **не просто сборник проектов**. Это **архив мышления**, лаборатория, где язык, компилятор, физика, графика и сеть переплетаются в единую живую систему. Здесь C++ не просто программирует — он **трансформируется**, **генерируется**, **переписывается сам собой**.

Проекты внутри — фрагменты большого, почти незримого движка, построенного не ради одной игры, а ради **возможности создавать любые игры** — с помощью **своего синтаксиса**, **своей логики**, **своего мира**.

---

## 🌐 Обзор

Этот репозиторий содержит серию взаимосвязанных проектов, объединённых общей экосистемой:

- **`QapLite`** — лёгковесный фреймворк для игр, сетей и UI.
- **`Mashkod`** — концепция DSL (domain-specific language) для описания игровой логики.
- **`AsmCppLike2Mashkod`** — **транслятор C++-подобного кода в ассемблероподобный MashkodASM**, с генерацией `.asm`, `.inl`, `.h`.
- **`Sgon`** — ядро системы: парсер, лексер, генератор, мета-компилятор.
- **`uidev_*`** — инструменты для разработки, редакторы, diff-утилиты.
- **`Demo*`** — прототипы механик: физика, торговля, транспорт, ИИ.

## 🔧 Ключевые проекты

### 1. `DemoMashkod/321/AsmCppLike2Mashkod/Sgon/` — **Ядро трансляции**

> **"C++ → MashkodASM"** — не компиляция, а **трансмутация**.

Это сердце всего. Здесь C++-подобный код парсится, анализируется и превращается в низкоуровневый `.asm`-код (MashkodASM), который затем может исполняться или компилироваться.

#### Особенности:
- **Генерация кода через `.inl`**: `QapGenStruct.inl`, `QapGenTemplDeclare.inl` — мета-шаблоны для структур и типов.
- **Парсинг C++-подобного синтаксиса**: `raw_cpp_lexem.inl`, `t_asmcpplike2016_lexer.inl`.
- **Рефлексия и RTTI**: `DeclareEnvRTTI.inl`, `MetaTypeGraber.inl`.
- **JSON и XML поддержка**: `main3_json_spirit_impl.inl`, `t_xml_lexem.inl`.
- **Множество версий `main`**: `main_2013_*.cpp` — следы эволюции языка.

#### Пример потока:
```text
C++-подобный код 
    → парсится (QapLexer.inl) 
    → генерирует структуры (QapGenStruct.inl) 
    → выводит MashkodASM (.asm) 
    → запускается (Sgon.exe)
```

### 2. `uidevs_from_nout_d_temp/` — **Инструменты разработчика**

> **"IDE для QapScript"** — но написанная вручную, как в 90-х.

Содержит:
- `qap_diff.cpp` — сравнение `.qap`-файлов (возможно, бинарных данных движка).
- `text_editor_bug_fix.cpp` — исправления редактора.
- `t_inl_file_lexem.*` — парсинг `.inl` как DSL.
- `data.qap` — пример данных движка.

Это **не просто утилиты**, а **черновики IDE**, где ты редактируешь не только код, но и **саму структуру проекта**.

### 3. `DemoSusliXLite/` — **2D Физический движок**

> Простой, но мощный — как Box2D, но твой(нет не мой, это Suslik`а, тут мой только рендер, забрал себе чтобы не потерять такую годноту).

Содержит:
- `RigidBody.h`, `PhysSystem.h`, `Solver.h` — основа физики.
- `Manifold.h` — обнаружение коллизий.
- `Joints.h` — соединения между телами.

**Назначение**: прототипирование игровых механик, возможно — для `DemoTransportBelt` или `IndeedSnake2Day`.// нет не для этого

---

### 4. `DemoTrading/`, `DemoNetwork/`, `DemoTransportBelt/` — **Демо-механики**

Каждое — **мини-игра с конкретной задачей**:
- **Trading** — экономика, инвентарь, сетевые вызовы.
- **Network** — сериализация, передача объектов.
- **TransportBelt** — логистика, конвейеры (как в *Factorio*).

Все используют `QapLite.h` — **единый фреймворк для всех демо**.

---

### 5. `IndeedSnake2Day/` — **Игра с душой**

> "Snake", но с графикой, меню, уровнями и системой объектов.

Содержит:
- `GameMenu.inl`, `LevelPack.inl` — UI и уровни.
- `GFX/` с `tank_hodun.png` — спрайты, возможно, отсылка к внутреннему миру.
- `voronoi.h`, `sweepline/` — **геометрические алгоритмы для ИИ или генерации карт**.

---

### 6. `cw02/CellWorld/` — **Клеточный компьютер**

> Не просто автомат — **вычислительная машина в сетке**.

Содержит:
- `2 бита памяти.png`, `делитель_частоты.png` — логические схемы.
- `frames/*.png` — запись симуляции.

**Идея**: построить процессор, память, логику — **внутри клеточного автомата**.

---

### 7. `Raytracer/` — **Собственный трассировщик лучей**

> Высокодетализированный, с поддержкой `.obj`, `.mtl`, `.png`.

Особенности:
- `sphere4096.bin` — сфера из 4096 полигонов.
- `view3d.exe` — визуализатор.
- `UnixVersion/` — кроссплатформенность.
- `assets/*.obj` — модели: танки, здания, персонажи.

Возможно, использовался для визуализации `CellWorld` или `DemoPlaner`.

---

### 8. `DemoPlanerV0/V2/` — **Генетический планировщик**

> Размещение объектов с помощью эволюционного алгоритма.

Содержит:
- `genetic_algorithm.inl` — отбор, мутации, кроссовер.
- `draw_map.inl` — отрисовка карты.
- Много `.txt` — логи, карты, данные.

## 🛠️ Сборка и запуск

Проекты используют **Visual Studio** (`.vcxproj`, `.sln`), но есть и `.bat`-скрипты для автоматизации:

```bat
Compile(Release).bat
CL_APP&RUN.bat
pack.bat
```

Для `Sgon`:
```bat
linkO2.bat        // Сборка с оптимизацией
run.bat           // Запуск сгенерированного кода
```
