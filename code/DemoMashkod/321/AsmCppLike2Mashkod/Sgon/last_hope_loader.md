## Почему это круто

1. **Глубокая эволюционная совместимость**  
   Файлы сохраняемые/загружаемые содержат полностью сериализованные описатели всех используемых типов (RTTI). Благодаря этому бинарь может быть корректно разобран новым или старым кодом, если совпадает базовая мета-структура описателей.

2. **Самодокументируемый бинарь**  
   Всё необходимое для расшифровки структуры данных — включая полные описатели типов — содержится внутри файлов.  
   А вот “описатели описателей” (мета-описатели) — присутствуют только в виде имён, без полной структуры, что делает формат компактнее, сохраняя при этом достаточную информацию для разбора.

---

## О файле `last_hope_loader.cpp`

`last_hope_loader.cpp` содержит код загрузчика последней инстанции.  
Он используется только в том случае, если обычный загрузчик не смог загрузить файл из-за несовпадения описателей типов.  
`last_hope_loader` пытается разрешить эти расхождения и загрузить данные, если это возможно.

<summary>Пояснения к критериям</summary>

- **Самоописание (RTTI):** В файле содержится информация о структуре данных.
- **Внешняя схема нужна:** Требуется ли внешний файл-схема.
- **Эволюция формата:** Насколько легко поддерживать совместимость между версиями.
- **Компактность:** Насколько маленький размер данных.
- **Скорость загрузки:** Время десериализации.
- **Многоязычность:** Есть ли поддержка разных языков программирования.
- **Без исходников читается:** Можно ли восстановить структуру без исходного кода.
- **last_hope_loader:** Есть ли механизм ручного разрешения несовпадений структур.
